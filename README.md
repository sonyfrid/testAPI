## 📋 О проекте

Коллекция API-тестов в **Postman** с проверкой JSON-схем, query-параметров и методов HTTP (GET, POST, PUT, DELETE). Тестируемый ресурс — [send-request.me](https://send-request.me/) через Swagger.
